# ld-bb.dev

Personal site for [Lilia Dassine Belaïd Bründler](https://ld-bb.dev) — senior mobile and frontend engineer.

This is a static site. Open `index.html` locally, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publishing

GitHub Pages currently builds from the `gh-pages` branch. After this redesign is merged into `master`, switch the Pages source to `master` / root so the live site updates:

Repository settings → Pages → Branch: `master` / `/ (root)`.

The `CNAME` file must remain `ld-bb.dev`.
